# Food Delivery Operations Intelligence

## Project Overview

An end-to-end Data Analytics project focused on analyzing food delivery operations, order performance, cancellations, and delivery efficiency using Python, SQL, and Power BI.

## Tools & Technologies

* **Python:** Pandas, data cleaning, exploratory data analysis (EDA)
* **SQL:** MySQL, KPI calculations, aggregations, CTEs, window functions
* **Power BI:** Interactive dashboards and business performance reporting
* **Jupyter Notebook:** Python analysis and visualization

## Dataset Overview

* Total Orders: 50,000
* Completed Orders: 49,132
* Cancelled Orders: 868
* Unique Order IDs: 50,000

## Key Performance Indicators

| KPI                             |        Result |
| ------------------------------- | ------------: |
| Completion Rate                 |        98.26% |
| Cancellation Rate               |         1.74% |
| Average Order Value             |        ₹38.17 |
| Average Estimated Delivery Time | 30.92 minutes |
| Average Actual Delivery Time    | 35.15 minutes |
| Average Delivery Delay          |  4.23 minutes |
| Late Delivery Rate              |        36.57% |

## Key Business Insights

1. **Driver Availability:** Driver unassignment accounted for 386 cancellations (44.47% of all cancellations).
2. **Traffic Impact:** Average delivery time was 39.89 minutes during high traffic compared with 30.59 minutes during low traffic.
3. **Weather Impact:** Average delivery time reached 47.07 minutes during stormy conditions.
4. **Delivery Distance:** Orders travelling more than 8–12 km averaged 54.87 minutes in delivery time.
5. **Operational Performance:** 49,132 of 50,000 orders were completed successfully.

## Business Recommendations

* Improve driver allocation to reduce driver-unassignment cancellations.
* Optimize delivery routes during high-traffic periods.
* Adjust estimated delivery times during severe weather.
* Review delivery strategies for longer-distance orders.
